# Projects

## RAG Profile Intelligence System

**Period:** July 2026 to present
**Tech stack:** FastAPI, ReactJS, Python, Gemini API, Pinecone, Docker, Pydantic, Tailwind CSS, Redux Toolkit, React Three Fiber (Three.js), and GSAP.

- Engineered a Retrieval-Augmented Generation (RAG) pipeline using Python, Gemini 2.5 Flash, and Pinecone serverless to query local Markdown knowledge-base data and provide context-grounded responses.
- Built an asynchronous FastAPI REST API with Pydantic validation, multi-turn chat support with rolling memory, and Docker containerization.
- Built a React frontend with Tailwind CSS and Redux Toolkit to centralize conversation state, cache active history, and safely render HTML to help prevent XSS.
- Integrated the chatbot into a 3D portfolio built with React Three Fiber and GSAP. Persona-based prompts for visitors such as HR and Interviewers adjust assistant behavior and suggested follow-up questions.
